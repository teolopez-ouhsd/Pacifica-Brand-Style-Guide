TRITON BLOCK v1.005
Athletic block typeface extended from the Pacifica High School Tritons wordmark.

v1.005: outline corners now come to a sharp point instead of being cut off (Shadow, Outline, Color).
v1.004: fixed stray shapes in the outline layer at the T arm tips and N top corner (Shadow, Outline, Color).
v1.003: Color style now defaults to Pacifica green outline with black fill; four built-in palettes.
v1.002: figures 0-9 are now the official Pacifica numerals, scaled to cap height.
v1.001: cleaned up corner joints on B, ? and the pound sign.

STYLES (all share identical spacing, so they stack in register)
  Solid    - the dark letter fill from the logo
  Shadow   - the logo's outer white layer. Place under Solid.
  Outline  - hollow rim only, one color
  Color    - Shadow + Solid in one color font. Default: black fill, Pacifica green (#006548) outline.
             Built-in palettes: 0 black/green, 1 black/white, 2 white/green, 3 white/black.
             On the web, any colors: @font-palette-values with override-colors (0 = fill, 1 = outline).

CUSTOM COLORS IN ANY APP
  Put Triton Block Shadow underneath, colored as the outline (e.g. #006548).
  Put Triton Block Solid on top at the same size and position, colored as the fill (e.g. black).


INSTALL
  Mac: double-click each .otf > Install Font (remove v1.000 first)
  Windows: right-click each .otf > Install for all users
  Web/Wix: upload the .woff2 files as custom fonts
