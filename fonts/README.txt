TRITON BLOCK v1.000
Athletic block typeface extended from the Pacifica High School Tritons wordmark.

STYLES (all share identical spacing, so they stack in register)
  Solid    - the dark letter fill from the logo
  Shadow   - the logo's outer white layer (0.88 unit offset). Place under Solid.
  Outline  - hollow rim only, one color
  Color    - Shadow + Solid in one color font (COLR/CPAL). Palette 0 dark on white,
             palette 1 white on dark. Supported in browsers, Figma, recent Adobe apps.

INSTALL
  Mac: double-click each .otf > Install Font
  Windows: right-click each .otf > Install for all users
  Web/Wix: upload the .woff2 files as custom fonts

CHARACTER SET (180)
  A-Z, small caps on a-z, tabular 0-9, punctuation, $ ¢ £ € ¥, math signs,
  © ® ™ ° « » ‹ › • · …, and accented letters for Spanish and Western European
  languages (Á É Í Ó Ú Ñ Ü ¿ ¡ plus À Â Ã Ä Å Ç Ê Ë Î Ï Ô Õ Û Ý Ÿ).

FEATURES
  kern  - pair kerning (AV, LT, TA, Y., etc.)
  c2sc  - caps to small caps
