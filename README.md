# Pacifica Tritons Brand Guide

Brand style guide for Pacifica High School (Oxnard Union High School District): official logos, colors, uniform and embroidery specs, accessibility, the Triton Block typeface, and usage rules.

## Publish on GitHub Pages

1. Create a new repository (for example `pacifica-brand`) or open an existing one such as `communications`.
2. Upload everything in this folder: `index.html`, `logos/`, `sheets/`, `fonts/`, both .zip files, `.nojekyll`, and this README.
   - To add it to an existing site, put it in its own folder, e.g. `pacifica/`, so the page lives at `/pacifica/`.
3. In the repo, go to **Settings > Pages**, set **Source** to "Deploy from a branch", choose `main` and `/ (root)`, and save.
4. After a minute the page will be live at `https://<your-username>.github.io/<repo-name>/`.

## Updating files

- Logos: replace files in `logos/svg` and `logos/png` with the same names, then rebuild `pacifica-tritons-logos.zip`.
- Fonts: replace files in `fonts/otf` and `fonts/woff2` with the same names, then rebuild `triton-block-fonts.zip`.
